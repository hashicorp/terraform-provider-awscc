# awscc_glue_workflow (Resource)

Resource Type definition for AWS::Glue::Workflow

## Example Usage

### Create a Glue Workflow

Create an AWS Glue workflow with default run properties and a concurrency limit to orchestrate crawlers, jobs, and triggers

~> This example is generated by Amazon Bedrock and verified to work using Terraform.

```terraform
data "aws_region" "current" {}

resource "awscc_glue_workflow" "example" {
  name                = "example-glue-workflow"
  description         = "Example Glue workflow orchestrating ETL jobs and crawlers"
  max_concurrent_runs = 1

  default_run_properties = jsonencode({
    environment = "dev"
    region      = data.aws_region.current.region
  })

  tags = jsonencode({
    "Modified By" = "AWSCC"
  })
}

output "workflow_name" {
  description = "The name of the Glue workflow"
  value       = awscc_glue_workflow.example.id
}

output "workflow_description" {
  description = "The description of the Glue workflow"
  value       = awscc_glue_workflow.example.description
}
```

## Schema

### Optional

- `default_run_properties` (String) A collection of properties to be used as part of each execution of the workflow
- `description` (String) A description of the workflow
- `max_concurrent_runs` (Number) You can use this parameter to prevent unwanted multiple updates to data, to control costs, or in some cases, to prevent exceeding the maximum number of concurrent runs of any of the component jobs. If you leave this parameter blank, there is no limit to the number of concurrent workflow runs.
- `name` (String) The name of the workflow representing the flow
- `tags` (String) The tags to use with this workflow.

### Read-Only

- `id` (String) Uniquely identifies the resource.
