# awscc_cloudwatch_otel_enrichment (Resource)

AWS::CloudWatch::OTelEnrichment enables OTel metric enrichment in CloudWatch, allowing CloudWatch vended metrics to be available for PromQL querying enriched with AWS resource tags and metadata.

## Example Usage

## Schema

### Optional

- `exclude_filters` (Attributes Set) Removes metrics from the include set. Absent or empty means nothing is removed. Evaluated after IncludeFilters, so ExcludeFilters always wins. (see [below for nested schema](#nestedatt--exclude_filters))
- `include_filters` (Attributes Set) Scopes enrichment to a subset of the account's telemetry. Absent or empty means all namespaces are in scope. Present means only these are. The service enforces a combined cap of 100 selectors across IncludeFilters and ExcludeFilters, and rejects more than one selector for the same namespace within a direction. (see [below for nested schema](#nestedatt--include_filters))
